GitHub Pages 从 homework3 分支的仓库根目录发布。本目录 index.html 自动进入 dist/。无需安装依赖或运行构建。

## 启动与验证

安装 Node.js 20 或更新版本，在本目录运行 `npm start`，访问 http://127.0.0.1:4173 。Windows 也可双击“启动网站.cmd”。请通过 HTTP 访问，不要直接双击 HTML。

`npm test` 执行 47 项测试，涵盖导入、统计、清洗、透视、分箱、时间聚合、多表合并、字段明细以及新分析流程。

## 三个栏目

2026-10-15 的 v11 将独立“图表”入口合并到“分析”。分析以同一组分析指标串联不同证据，不再提供重复的图形陈列页。全站中英双语，浅靛蓝侧栏，统一系统字体。

| 栏目 | 功能 |
| --- | --- |
| 数据 | CSV / TSV / JSON / Excel 导入、多数据集切换、真实企鹅数据、样本构成、观测时间覆盖、记录完整度、重复与疑似异常检查、字段画像与随字段更新的原始明细、排序分页、CSV/JSON 导出 |
| 处理 | 四个按钮：缺失处理、去重、更名、计算列；共用参数区、前后数量对照与原始记录预览、应用栏。支持撤销、多表合并和操作记录 |
| 分析 | 比较群体分布、检验变量关联、分层核对均值与构成；按字段类型适配时间分析或类别交叉计数。图形、统计和结论同步更新；支持 SVG、分析 CSV、分组与透视明细 |

## v12 更新：处理对照与数据概览

本轮更新处理对照与数据概览，通过 homework3 分支统一发布。

- 缺失处理用空值数量、完整/空值比例条和具体原始行展示“空值 → 填充值”或“整行删除”。
- 去重用真实保留/删除数量和重复组展示，明确保留、删除的行号与值。没有重复时直接说明所有记录保留。
- 更名用两张同源小表直接对照旧表头、新表头和数据类型；值变化单独计数。
- 新字段显示字段数变化、计算公式和逐行输入/结果，缺失及除零结果显示为空值。
- 移除处理页的叠加直方图、去重流向图与字段连线；处理结果随正常页面滚动。
- 多表合并也使用行数/字段数、匹配比例和新增列高亮表格，不再对任意数值字段绘制分布图。
- 修复输入框失焦时重建应用按钮、导致首次点击未生效的问题。
- 数据页新增样本构成（含缺失与其余类别）、年度观测覆盖、完整记录占比与字段缺失排行。
- 重复记录、疑似异常和常量字段支持查看详情；点击缺失字段可定位字段画像及其缺失值明细，不改变数据范围。
- 没有时间字段时展示字段类型、唯一值字段与常量字段；字段和时间选择分别保存在各数据集会话状态。

## 应用实例

默认进行“体重 · 物种分组分析”，使用 Palmer Penguins 的真实观测：

1. 差异与分布：箱线图和原始观测点比较不同物种的体重中位数、离散程度和重叠，旁边显示均值与有效样本量。
2. 变量关联：鳍肢长度为横轴、体重为纵轴绘制散点，颜色沿用物种。对照整体 Pearson r 与各物种内部 r，区分群体之间与群体内部的关系。
3. 分层核对：按性别比较各物种的分层均值，同时显示各性别样本占比。结论检查整体均值最高的物种在多少个可比较分层中仍最高（并列最高也计入）。

所有结论来自当前工作数据的运算，没有写死样例统计。切换比较维度、分析指标、关联指标或分层字段，整组分析一起更新。导入数据根据字段类型设置初值；分析设置分别保存在各数据集的会话状态中。

日期字段作为比较维度时，改用按日/周/月/年的均值折线；没有数值字段时，改用类别频数与交叉计数热力图。缺少可用关联指标时省略关联图。字段被更名或删除后自动校正设置。

## 交互与计算口径

- 已删除全局筛选、图形点选筛选和散点框选。分析基于完整工作数据；点击观测点只查看记录，不缩小数据范围。
- 箱体为 Q1–Q3，横线为中位数，须为 1.5×IQR 内观测极值。每组最多绘制 65 个真实点；统计使用全部有效值。
- 分组图最多显示记录数较多的 8 组，时间图最多显示前 48 个有效时段，覆盖数量明确展示；导出包含全部分组。
- 散点最多绘制 1,200 个等距抽样的真实点；Pearson 使用全部有效配对。常量字段或配对不足返回空值，相关不等于因果。
- 分层最多单列 4 个类别，其余合并为灰色占比。分母包含该组全部记录，包括缺失类别。上排圆点使用均值刻度，下排占比独立使用 0–100% 刻度。
- 分层比较描述当前观测，不自动声称统计显著性或因果。CSV 包含所有分组、所有分层及对应样本量、分位数和相关系数。
- 数值统计忽略缺失，标准差为样本标准差，分位数线性插值。时间图不将缺失时段补零，连线仅连接已有时段。
- “统计明细与透视表”提供分组聚合、透视、全部数值字段的描述统计。count 统计非空指标；缺失分组保留。
- 处理参数变更仅预览，应用后修改当前数据集，支持最近 20 步撤销。前后分布使用相同坐标和分箱。
- 多表合并可使用已有数据集或新文件。空键不匹配，数字与文本键区分，重名列加后缀。
- 单文件最多 5 MB、20,000 行、80 列。CSV/TSV 表头唯一；JSON 为扁平对象数组。Excel 可选工作表。
- 数据仅保留在当前页面会话中，同名文件不会覆盖；刷新前请导出。只有语言偏好持久化。
- pandas 常用能力以本地 JavaScript 实现，不是 Python/pandas 运行环境。

## 真实数据

默认使用 [Palmer Penguins](https://allisonhorst.github.io/palmerpenguins/)：344 条真实科考观测、8 个字段、3 个物种、2007–2009 年，19 个缺失单元格，0 条重复记录。由 Kristen Gorman 与 Palmer Station Antarctica LTER 采集，CC0 授权。

`dist/data/penguins.csv` 保留上游原文件，penguins.js 只将 NA 识别为空值，没有补造观测。source.json 记录来源、日期与 SHA-256。测试校验文件完整性和已知统计。

## 主要文件

- dist/app.js：双语界面、数据集状态、导入导出和事件。
- dist/study-engine.js：分析字段适配、分组、关联、分层和完整分析导出。
- dist/study-view.js：应用分析图形与根据证据计算的结论。
- dist/engine.js、dist/visual-engine.js：表格计算、分箱、时间处理与合并。
- dist/prepare-engine.js、dist/prepare-visuals.js：处理预览运算与清楚标记的前后对照。
- dist/data-overview.js：数据质量审核、样本构成与观测时间覆盖。
- dist/field-details.js、dist/workspace.js：字段明细、分页与独立数据集状态。
- dist/chart-stats.js、dist/extra-charts.js：图形统计与保留的可复用图形工具。
- dist/vendor/：SheetJS CE 0.20.3（Apache-2.0），保留许可证。
