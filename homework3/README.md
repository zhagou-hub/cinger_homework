# DataLens 数据探索工作台

可视化导论课程项目。中英双语，浏览器本地处理数据。2026-10-15 更新：以四个栏目串联数据、处理、分析和图表，采用深靛蓝侧栏、紫蓝交互与多色图表。

## 启动与验证

安装 Node.js 20 或更新版本，在本目录运行 `npm start`，访问 http://127.0.0.1:4173 。Windows 也可以双击 `启动网站.cmd`。无需安装 npm 依赖，请通过 HTTP 访问，不能直接双击 HTML。

运行 `npm test` 执行 38 项测试，涵盖导入、统计、清洗、透视、数值边界、共享分箱、异常值、时间聚合和多表合并。

## 四个栏目

| 栏目 | 功能与可视化 |
| --- | --- |
| 数据 | CSV / TSV / JSON / Excel 导入、工作表选择、真实企鹅数据、缺失热力图、字段画像、直方图、箱线图、类别频数、搜索排序和分页 |
| 处理 | 顶部四个功能按钮切换缺失处理、去重、更名、计算列；下方共用参数区、效果区和应用栏。参数变化自动预览，应用后可撤销；多表合并折叠展示 |
| 分析 | 分组箱线与观测点、百分比堆叠、散点矩阵、描述统计、分组聚合、透视、相关性矩阵、按日/周/月/年汇总；点击相关性色块打开散点图 |
| 图表 | 12 类图形：柱状、折线、直方、散点、箱线、环形、相关热力、分组箱线与观测点、百分比堆叠、类别交叉热力、平行坐标、散点矩阵；颜色分组、图表建议、构成与分布、观测点详情 |

导入、导出只在“数据”，操作记录、撤销、重置只在“处理”。顶栏显示当前数据集的完整行数和中英切换，已移除手工筛选、图表点选筛选和散点框选。完整数据工作表只保留在“数据”，图表页的记录按需弹出。

## 核心交互

1. 图表与统计始终使用当前数据集的完整记录；工作表关键词搜索只影响工作表。
2. 点击相关性色块进入对应的散点图，点击观测点查看单条记录，不改变数据范围。
3. 清洗操作先预览影响，再应用；可撤销最近 20 步。
4. 多表合并展示匹配数、未匹配数、一对多新增行数和前 5 行结果。
5. 导出全部工作数据 CSV/JSON、聚合 CSV、图表 SVG、相关矩阵 CSV 或操作历史 JSON。

## 处理页交互

- 四个按钮共用一个效果区：缺失数量与分布、重复记录去向与位置、字段映射、新字段公式与分布。
- 点击功能只切换操作，参数更改仅计算预览；点击“应用处理”才修改当前数据集。无变化或参数无效时不允许应用。
- 每个数据集分别保留功能选择、参数和最近已应用的效果。撤销恢复数据与对应参数；变更参数后重新进入预览。
- 重复数据展示真实重复数量，默认企鹅数据显示 0 条重复，并禁用应用按钮。
- 多表合并保留在折叠区，使用独立的应用按钮，避免误应用另一项预览。

## 新增图形口径

- 缺失热力图按工作表行序分成最多 48 段，所有行均参与统计；橙色深浅表示该字段在该段的缺失比例。
- 清洗哑铃图比较各字段缺失数量（最多展示 10 列），新增字段的处理前值为 —。
- 分组箱线使用线性分位数和 1.5×IQR 内观测极值，最多 8 组；每组最多显示 80 个原始点，统计不抽样。
- 堆叠图与类别交叉热力图统计记录数，每个维度最多 8 类；页面明确显示覆盖数量，百分比以显示类别为分母。
- 平行坐标每轴独立按完整数据 min–max 归一化，最多 5 个数值字段、300 条完整记录；常量列置中，点击检查原记录。
- 散点矩阵最多 4 个数值字段、200 条等距抽样记录；对角线为直方图，相关系数使用全部有效配对，点击字段对进入散点图。
- 五种新增探索图形可在“图表”中选取并导出 SVG。

## 数据与计算口径

- 默认使用 [Palmer Penguins](https://allisonhorst.github.io/palmerpenguins/) 真实科考数据：344 条记录、8 个字段、3 个物种、2007—2009 年、19 个缺失单元格、0 个重复行。数据由 Kristen Gorman 与 Palmer Station Antarctica LTER 采集，CC0 授权。
- `dist/data/penguins.csv` 保留上游原文件；`penguins.js` 仅把 NA 识别为空值。`source.json` 记录获取地址、日期与 SHA-256。测试校验原始文件完整性、物种数量、测量范围和相关系数。
- 图表直接选择字段、图形、聚合与颜色。默认设置根据数据字段类型选择，不绑定某个样例。散点显示成对有效观测与基于完整有效配对计算的 Pearson r。
- 支持当前页面会话内同时保留多个数据集；同名文件不会覆盖。左侧切换保留各自的工作表搜索、已应用清洗、撤销记录、分组与图表设置。四项处理参数分别保留，切回后按当前数据重新计算未应用预览；多表合并的未应用预览不保留。刷新前需导出。
- 多表合并可选择会话中已有数据集，也可导入另一张表。
- 全站使用统一系统字体与字号；长字段名换行或截断，不缩小字号。去掉问题卡片、英文眉题和叙事式标题。
- 所有分析和数据导出使用完整工作数据；工作表搜索与排序只影响工作表展示。
- 处理操作作用于完整工作数据。应用后修改数据并保留撤销记录，页面有明确提示。
- 直方图展示全部有效值频数，最后一个区间包含最大值。
- 清洗对比使用相同横轴、分箱与纵轴上限。均值可能不变，而分布和缺失数发生变化。
- 箱线图使用 1.5 × IQR 标记疑似异常，系统不会自动删除。
- 散点超过 1,500 有效点时抽样显示；统计和明细使用全部记录。
- 统计忽略缺失数值；样本标准差 ddof=1，分位数线性插值；Pearson 成对有效值计算，常量列返回空值。相关不代表因果。
- 分组保留缺失键，count 统计非空指标；无有效数值时 mean 返回空值、sum 返回 0。
- 时间按日/周/月/年求和，周从周一开始，缺失时段不补零。时间图最多展示前 60 个时段，图表截断有提示。
- 合并空键不匹配，数字与文本键区分类型；重名列自动加后缀。多对多展开后仍受行数限制。
- 单个文件最多 5 MB、20,000 行、80 列。CSV/TSV 使用 UTF-8，表头非空唯一；JSON 是扁平对象数组。
- Excel 可选工作表，首行为表头；文本标识符保留前导零，日期单元格转为 ISO 日期。
- 以 JavaScript 实现 pandas 常用能力子集，不是 Python/pandas 执行环境，不覆盖全部 API。
- 数据计算在浏览器本地完成；仅语言偏好持久化，刷新会恢复示例，请先导出成果。

## 文件结构

- dist/index.html、dist/style.css、dist/theme.css：页面与样式；theme.css 统一整站靛蓝配色。
- dist/app.js：双语界面、图表与交互。
- dist/engine.js：基础表格计算。
- dist/prepare-engine.js、dist/prepare-visuals.js：四种处理的纯预览运算和共享效果区图形。
- dist/chart-stats.js、dist/extra-charts.js：图形统计、分组、热力、箱线、平行坐标和散点矩阵。
- dist/workspace.js：数据集状态隔离与按字段类型选择默认分析设置。
- dist/visual-engine.js：分箱、异常值、时间聚合与合并。
- dist/vendor/：SheetJS CE 0.20.3（Apache-2.0），保留许可证，用于本地 Excel 解析。
- tests/：38 项 Node 测试及验收样本。
- server.mjs、启动网站.cmd：本地启动。
- .openai/hosting.json：原 Sites 项目与静态目录配置。
