# 石油勘探开发智能化案例集

访问地址：https://zhagou-hub.github.io/cinger_homework/bighomework/

覆盖 13 个作业环节、61 个场景，均提供专业背景、案例流程和可运行示范。包括原有 15 个补充案例、本轮新增 45 个案例，以及保留的老师“测井曲线智能分层”示例。所有演示使用教学样本与简化计算，不作为现场工程验证结果。

首页新增可旋转、缩放和自动导览的三维概念井场。选择环节后，可从右侧直接进入对应演示。案例库提供左侧关键词、环节、方法和难度筛选，右侧展示预览卡片；作业链按 13 个环节顺序展开，并提供三阶段定位。

站点为纯静态 HTML / CSS / JavaScript。案例索引先加载，60 个独立案例载荷按需读取；老师原示例继续独立注册。无远程运行依赖，可通过本地 HTTP 服务或 GitHub Pages 浏览。

## 主要文件

- `assets/core/atlas3d.js`：三维几何建模、投影、深度绘制、选择与镜头交互。
- `assets/core/explorer.js`：案例筛选、分页卡片与分阶段作业链。
- `assets/core/expansion.css`：新增页面与窄屏布局。
- `assets/cases/builtin-cases.js`：案例元数据索引与按需加载器。
- `assets/packages/`：按案例拆分的完整背景、流程和独立演示资源。
- `assets/previews/`：新增案例的计算快照预览。

新增演示覆盖剖面、空间热图、频谱、响应面、路径、网络、三元配方、甘特图、玫瑰图、相图和误差诊断等表现形式。指标由当前教学输入计算；固定随机种子可复现，支持参数调节、输入与结果切换、逐步演示和数据导出。

开发验证：61 个案例的场景覆盖、三部分内容、文件引用与脚本编译通过检查；新增 45 个演示完成浏览器打开与参数交互检查，270 组参数边界计算检查通过。参考界面思路来自 https://github.com/xiao1783/tiangong-petro-atlas ，本项目保留原有教学框架与案例格式。
