# 见数 · 可视化导论课程重构

基于 [李昕老师的原课程仓库](https://github.com/cinger007/vis) 重构的课程作业。保留原课程五章、27 小节及讲解／代码／演示内容，新增浅色学习首页、学习路线、章节搜索、手动学习进度和交互实验室。

原课程：中国石油大学（华东），授课教师李昕；主要参考教材：陈为《可视化导论》。原始基线提交：`35a66ecb5e35e8c4f2c54a007cb6c590255b6f06`。新增界面用于课程重构作业，不是原课程的官方新版。

## 本地预览

在本目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:4173/ 。也可双击 `start-preview.cmd`，按窗口中的地址打开。退出服务请在终端按 Ctrl+C。页面需要通过 HTTP 加载，不要直接双击 HTML，否则浏览器可能禁止读取 CSV 或 ES modules。

## 文件结构

- `index.html`、`landing.css`：全宽滚动首页，整合课程介绍、五章目录与学习路径。
- `hero-scene.js`：本地生成的三维曲面与粒子背景，包含透视投影、动态光照、鼠标视角响应和暂停控制。
- `styles.css`、`portal.js`：章节卡片、搜索筛选与学习进度展示。
- `chapters/`：兼容旧目录地址，自动进入第一章“数据”。
- `lab/`：多数据分析工作台、同数据图形对照、色带映射与灰度检查；`data.js` 负责 CSV 与统计，`charts.js` 绘制七类图形，`lab.js` 组织交互。
- `shared/`：全站统一顶部主导航、随栏目变化的侧栏、五章阅读主题和本地学习进度。
- `lesson-01/` 至 `lesson-05/`：原课程五章、讲义、数据和教学演示。
- `supplementary/`：原课程补充案例；缺失的原演示已在目录标记。
- `vendor/d3.min.js`、`vendor/d3.LICENSE`：主章节使用的本地 D3 7.9.0 与许可证。

## 数据与交互

新生数据来自原课程 `lesson-01/data/newstudent.csv`，是 DeepSeek 合成教学数据：80 条，17 岁 31 人，18 岁 49 人，不代表真实学生或总体分布。实验室还提供原课程 366 条 2024 年天气示例和 50 州历史统计示例。原天气文件未附采集说明；州级统计不是当前统计。色彩矩阵为明确标注的固定示例数据。

全站顶部统一显示“课程首页、课程讲解、交互实验室、补充案例”四个主栏目。首页不设置侧栏，下滚可浏览课程章节、学习路径与搜索筛选，不再设置“课程功能入口”和“课程学习方法”两个区块。点击课程讲解直接进入第一章“数据”，不再显示中间目录页；侧栏显示五章路径和当前章小节，返回目录会回到首页的课程章节区域。实验室与案例页保留各自的子目录。

中英文切换统一放在固定顶栏，由共享导航为所有内容页加载同一组件与样式，包括首页、五章讲解、实验室、案例目录及独立演示。语言选择保存在 `wbl-locale`，跨页面保持并同步同源标签页；URL 的 `?lang=en` / `?lang=zh` 可显式指定语言。`shared/site-translations.js` 补齐新增界面及动态提示的本地词典，保留既有课程双语正文。切换时不重载页面、不重置实验选择，不改写 CSV 原值、用户输入或程序代码。首页搜索同时支持中英文关键词。

首页三维场景通过原生 Canvas 绘制透视投影的生成曲面与粒子轨道，不加载外部图片、视频或三维库。支持暂停/恢复，响应系统减少动态效果设置，并在页面隐藏或场景滚出视口时停止动画。该场景是明确标注的生成图形，不是教学数据统计图。

学习进度由用户显式标记完成，可撤销；保存在当前浏览器 `localStorage`（键 `vis-learning-v1`）。访问章节只更新最近阅读位置，不会自动标记完成。不同浏览器、设备和站点地址不共享进度。

实验室支持分组比较、数值分布、相关关系和时间趋势四种任务；提供柱状、圆点、直方、箱线、散点、折线和日历热图。可选择字段、计数／平均／总和、排序和分箱数量，并叠加多个类别筛选。缺少所需字段时，相应任务或图形不可选。类别较多时最多显示 12 组，原始明细与导出仍保留全部筛选记录。

点击图形或在散点、折线的空白处拖动，可联动选择原始记录、统计摘要和明细；选择不是删除或重新聚合全图。对照区使用完整筛选范围，不使用临时图形选择，支持柱状／圆点、直方／箱线、原始散点／拟合、折线／日历热图成对对照。州级事件数可换算为每十万人指标。Pearson r 仅描述线性相关；普通最小二乘拟合包含截距，不声称因果。

CSV 导入完全在浏览器内处理，最多 2 MB、5,000 行、100 列；UTF-8 逗号分隔，日期使用 YYYY-MM-DD。自动识别数值与日期，ID／序号视为类别，空数值不按零处理。数值分位数采用线性插值；箱线须线采用 1.5×IQR 规则。时间视图同日先取平均，移动平均为当前和前 6 个有效观测日；原始记录摘要与按日聚合的统计口径明确区分。

探索任务先预测再验证，可一键载入对应分析。实验记录在当前页面会话内最多保存 6 条，刷新后不保留；支持导出 Markdown 记录、当前记录 CSV 与图形 SVG。CSV 导出保留数值精度，并防止字符串被电子表格当作公式执行。色彩实验保留三类语义映射，增加灰度与标签开关；灰度不等于色觉缺陷模拟。

实验室各实验下方提供相关知识点链接，可直达数据属性、分组聚合、视觉通道、坐标比例尺、颜色空间和色觉友好设计等课程小节。

## 修复与验证

主章节 D3 已本地化；修复第五章天气日期键不匹配、日历周列与裁切、螺旋起点导致日期缺失、月份标签重叠以及悬浮提示残留；修复第三章无效色值和部分缺失导航链接。

实验室可执行 `node --test lab/data.test.cjs`，六项检查覆盖 CSV、日期、缺失值、分位数、相关系数及原课程三组数据。浏览器已验证七类图形、组合筛选、空结果、真实拖动框选、任务反馈、图形对照、灰度与标签、本地 CSV 导入、SVG／CSV／记录导出。导出的 SVG 已做 XML 解析、CSV 已核对 366 条记录。原课程搜索、完成标记和代表性演示在此前迭代中已验证。手机端为可横向滑动的图形区域。

补充独立案例仍保留原有外部 CDN 依赖；原课程的外部参考资料也需要联网。本次不宣称整站完全离线或对所有原教学内容做学术审校。
